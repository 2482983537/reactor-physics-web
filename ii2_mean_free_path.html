01
0~1 MIN · 平均自由程的含义

1 cm³ 里有 10²² 个核：中子的「茫茫核海」

典型压水堆中，1 立方厘米的核燃料或慢化剂内，一个中子四周充斥着约 10²² 量级个原子核。中子在核海中穿行，碰撞前飞行距离或近或远——这些距离的平均值就是中子平均自由程。

NUCLEI DENSITY

核燃料（UO₂，富集度 4.5%）：1 cm³ 中约 2×10²² 个铀核；轻水：约 10²³ 个原子核（H+O 合计）。典型量级估计。

NEUTRON DENSITY

堆内中子通量密度约 10¹³~10¹⁴ n/(cm²·s)，热中子速度约 2.2×10⁵ cm/s → 中子密度约 10¹⁰ /cm³（10¹⁶/m³ 量级，随功率水平变化）。

比例

原子核比中子多约 10¹²~10¹⁴ 倍——中子在堆内「几乎必然」不断与核相撞。

λ 的直觉

碰撞前的飞行距离是随机的：有的中子刚出发就撞上，有的穿行很远。它们的平均值就是平均自由程 λ。

拓展 · 从"追踪一个中子"到"算一片沙丘"
· 教材的比喻：单个中子的运动完全随机、无法逐个追踪——就像不追踪每一粒沙，却仍能研究沙丘的形状。反应堆物理研究的是宏观分布（PPT《绪论》）。
· 本页的蒙特卡洛抽样是数值计算的两大路线之一（随机模拟）；另一条是直接求解扩散/输运方程（III、VI 章）。
· 好慢化剂的三条标准：散射截面大、吸收截面小、每次碰撞带走尽可能多的能量——轻核（H、C）一次碰撞就能让中子掉一大截能量，重核几乎只让它拐弯。定量指标叫「慢化比 ξΣs/Σa」（III-2 预告）。

02
1~2 MIN · 首次反应概率分布函数

飞行距离是随机的：直方图收敛成指数曲线 p(x) = Σe^(−Σx)

碰撞的随机性让飞行距离成为一个随机变量。当出射中子数从 100 增加到 100000，飞行距离的频率直方图会越来越光滑——光滑曲线就是首次反应概率分布函数。

首次反应概率分布函数描述「中子在运行距离 x 后首次与核发生反应」的概率密度，它是计算 λ 的关键：

两个事件同时发生：一是中子穿行距离 x 而不发生反应（概率 e−Σx，来自薄靶实验的指数衰减）；二是在 x 附近的 dx 内发生反应（概率 Σdx，来自宏观截面的物理意义）。

03
2~3 MIN · 平均自由程的计算与典型值

λ = 1/Σ：数学期望给出的简洁结果

对概率密度 p(x)=Σe^(−Σx) 求数学期望，得到 λ = 1/Σ：平均自由程是宏观截面的倒数。不同介质、不同反应类型的 λ 差异巨大。

典型压水堆介质中，热中子的平均自由程（教师脚本参数）：

怎么读这张表

慢化剂中散射 λ 只有 0.38 cm——中子在慢化剂里频繁碰撞（这正是「慢化」的物理）；慢化剂中吸收 λ 长达 27 cm——好慢化剂「会撞不会吃」。

控制棒

吸收 λ 仅 0.85 cm——中子进入控制棒很快被吃掉，这就是它能「刹车」的原因。

核燃料

燃料中 λ ≈ 3.5 cm，而燃料芯块直径只有约 1 cm——中子在燃料里平均能跑出去、进入慢化剂。这个简单事实支撑了整个栅格设计。

λ 与反应类型有关

吸收 λ 越大 → 中子可穿行更远不被吃；散射 λ 越小 → 中子容易多次散射。总 λ 由各反应道的 Σ 竞争决定。

指数族的记忆锚点
同一条指数曲线贯穿本章：
· II.1：薄靶穿透率 I/I₀ = e−Σx（一堆中子的存活率）
· II.2：首次反应概率密度 p(x) = Σe−Σx（一个中子的距离分布）
· λ = 1/Σ：p(x) 的数学期望 = 穿透率降到 36.8% 的距离。

脚本实操 · 进实验室

亲手抽样：自由程实验室

教师提供了 Matlab 脚本 free_path_sampling 与交互设计手稿：输入宏观截面（0.01~3 cm⁻¹），观察中子首次反应位置与平均自由程。网页版实验室已按此规格实现。

function [free_path_samples, mean_free_path] = free_path_sampling(sigma, number)
% Sigma 介质的宏观截面参考取值，单位为 cm^(-1)
% 核燃料的七群热中子总反应截面取值为 0.564406
%   其中吸收反应的截面为 0.28278；散射反应的截面为 0.281626
% 慢化剂的七群热中子总反应截面取值为 2.650380
%   其中吸收反应的截面为 0.0372390；散射反应的截面为 2.613141
% 控制棒的七群热中子总反应截面取值为 1.840480
%   其中吸收反应的截面为 1.178360；散射反应的截面为 0.662127
free_path_CDF     = rand(number, 1);
free_path_samples = -(1.0 / sigma) .* log(1.0 - free_path_CDF);   % 反变换抽样
mean_free_path    = 1.0 / sigma;
histogram(free_path_samples, DisplayStyle='stairs', Normalization='probability')
end

0~1
1 cm³ 核燃料/慢化剂内一个中子四周充斥着海量原子核；从一点飞出的中子穿行时很可能与核碰撞，碰撞前飞行距离或近或远，平均值即中子平均自由程。
1~2
飞行距离具有随机性，假设概率密度 p(x)，λ 用数学期望计算。p(x) 即「首次反应概率分布函数」——出射中子数从 100 增加到 100000，直方图逐渐光滑成该曲线（脚本 free_path_sampling 产生数据）。
2~3
首次反应概率=（走过 x 不反应）×（在 dx 内反应）= e^(−Σx)·Σdx。据此得 λ=1/Σ。给出核燃料/慢化剂/控制棒各自的吸收、散射平均自由程：慢化剂中最易碰撞、控制棒内穿行距离最小；核燃料内中子可跑出芯块进入慢化剂。
